# Feraxis Minecraft Resource Packs

Public resource-pack releases for the Feraxis Minecraft server.

## Java Edition

`java/vanilla-plus-english-patch-26.2.zip` is an English-only translation patch for the Vanilla+ datapack. It contains the official Vanilla+ names for custom items and advancements, including `Gingerbread Man`.

Load this patch after the full Vanilla+ client resource pack so Java Edition clients resolve the custom `item.moldomre.*` and `advancements.*` keys. The server-side datapack remains in `datapacks/paper-26.2/`.

The Bedrock export is not included in this repository.
